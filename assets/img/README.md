# assets/img

Déposer ici la photo de profil sous le nom exact **`portrait.jpg`**
(format portrait, ~600×720 px minimum, cadrage buste).

Elle est utilisée à deux endroits :
- le portrait animé de la page d'accueil (`index.html`) ;
- la photo du document CV imprimé / exporté en PDF.

Si le fichier est absent, le site affiche automatiquement un monogramme
de repli et le CV imprime un cadre tramé — rien ne casse.
